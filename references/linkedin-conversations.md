# LinkedIn conversation playbook

Use this reference for public comments, author replies, and monitored post threads.

## Triage

Classify each item before drafting:

| Type | Default handling | Escalate when |
| --- | --- | --- |
| Genuine question | Answer from approved facts; name uncertainty | The answer needs private, legal, pricing, security, or account data |
| Constructive addition | Acknowledge the specific contribution and add context if useful | It reveals a material error in the original post |
| Praise | Thank the person without turning it into a sales pitch | The praise makes a claim the brand cannot verify |
| Correction or disagreement | Address the strongest substantive point calmly | The topic is regulated, reputationally sensitive, or factually unresolved |
| Lead signal | Be helpful in public; move private only with a clear reason | Personal or commercially sensitive details are required |
| Complaint | Acknowledge, avoid promises, and route to the owner | Safety, legal, harassment, crisis, or personal data is involved |
| Spam or abuse | Recommend no reply, moderation, or escalation | Threats, targeted harassment, or coordinated activity appears present |

## Reply rules

- Read the parent post and the full available thread before replying.
- Respond to the person's actual point, not merely its sentiment.
- Do not ask a question unless the answer would be useful and someone will handle it.
- Do not reveal private data, confirm an account relationship, accept liability, promise a remedy, or impersonate a named employee.
- Match warmth and detail to the conversation while preserving the brand's boundaries.
- Mark facts that require an internal owner and provide a safe holding reply only when one is useful.

## Monitoring record

For every reviewed item, retain the post or thread identifier if available, author, timestamp, classification, risk level, proposed action, draft, owner, and status. Distinguish “observed,” “drafted,” “escalated,” and “sent.” A drafted response is never evidence that it was published.
