# Content calendar

## Inputs
Get date range, channels, audience, goals, campaign dates, publishing capacity, source assets, and approval constraints. If dates or capacity are absent, create a lightweight proposed cadence and label it as an assumption.

## Workflow
1. Map goals to a small set of content themes.
2. Balance educational, proof, product, and conversation-starting formats as appropriate to the brief.
3. Assign a topic, platform, objective, source asset, owner, and review status to each slot.
4. Identify gaps and production dependencies.

## Output
Provide a dated Markdown list, then `Themes`, `Gaps`, and `Production checklist`. Do not claim optimal posting times without supplied data. Use MCP only to inspect an authorized calendar; do not alter it without confirmation.
