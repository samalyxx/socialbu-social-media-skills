# Post repurposer

## Inputs
Request source material, source and destination platform, intended audience, objective, constraints, and any facts that must remain unchanged.

## Workflow
1. Extract the one defensible insight and supporting evidence.
2. Rebuild the hook and structure for the destination context; do not merely shorten the source.
3. Preserve attribution, links, claims, and required disclosures.
4. Compare the draft to the source for accuracy.

## Output
Return `Adapted draft`, `What changed`, and `Facts retained`. Draft-only by default. Never remove safety, legal, pricing, or attribution language without an explicit instruction and a stated rationale.
