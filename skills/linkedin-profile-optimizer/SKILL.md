# LinkedIn profile optimizer

Make a personal profile clearer, more credible, and more relevant to the opportunity the owner wants. Read [LinkedIn profile](../../references/linkedin-profile.md) and apply [LinkedIn writing](../../references/linkedin-writing.md) to rewritten copy.

## Intake

Obtain the current profile text or export, target audience, desired opportunity, current role, verified experience and results, differentiators, proof, voice, privacy constraints, and sections in scope. If only a public URL is supplied and no authorized browsing tool is available, ask for the relevant text rather than implying the profile was inspected.

## Workflow

1. State the positioning the current material supports: who the person helps, what work they do, why it is credible, and what opportunity the profile should invite.
2. Audit each supplied section against the checklist in the profile reference.
3. Prioritize changes by impact and confidence. Distinguish weak expression from missing evidence.
4. Draft replacement copy in the profile owner's first-person voice where appropriate.
5. Verify every employer, title, date, credential, client, number, and result against supplied facts.
6. Identify supporting assets or profile fields the user should review manually; do not claim to see unsupplied visuals or settings.

## Output

Return `Positioning`, `Priority audit`, `Ready-to-paste copy by section`, `Evidence or facts to verify`, and `Manual profile checklist`. When offering variants, name the positioning tradeoff each one makes.

Do not invent searchable keywords, achievements, endorsements, recommendations, or career history. Do not claim a rewrite will guarantee discovery or opportunities. This skill proposes profile changes and does not apply them.
