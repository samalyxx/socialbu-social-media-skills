# Analytics review

## Inputs
Use a supplied report or authorized SocialBu analytics. Ask for date range, comparison period, goal, channels, and known campaign changes.

## Workflow
1. Verify metric names, period, and coverage before interpreting results.
2. Identify notable changes and breakouts without treating correlation as causation.
3. Compare content patterns only where enough examples exist.
4. Convert findings into one to three measurable next tests.

## Output
Return `Performance snapshot`, `Observed patterns`, `Hypotheses`, `Recommended tests`, and `Data caveats`. Never fabricate metrics or promise growth. This skill reads and analyzes only; it does not change reports or posts.
