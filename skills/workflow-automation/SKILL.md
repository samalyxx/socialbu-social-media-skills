# Workflow automation

## Inputs
Ask for trigger, source, conditions, action, exception handling, owner, approval requirement, and desired outcome. Check `references/socialbu-capabilities.md` before making product-specific claims.

## Workflow
1. Describe the current manual process and its failure modes.
2. Propose the smallest automation that removes a repetitive step.
3. Add explicit conditions, a review point, and an off switch.
4. Identify what should remain manual or require confirmation.

## Output
Provide `Trigger`, `Conditions`, `Actions`, `Exceptions`, `Review`, and `Success measure`. Design only by default. Do not create, enable, disable, or modify a SocialBu automation without immediate explicit confirmation via the MCP operator.
