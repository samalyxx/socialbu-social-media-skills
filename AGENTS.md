# Repository instructions

This repository is a portable skill bundle for SocialBu-oriented social media work.

1. Route a request to the narrowest relevant `skills/*/SKILL.md` and read it first.
2. Use draft mode when no connected SocialBu data is available.
3. Treat every external state change as confirmation-gated: publish, schedule, update, delete, approve, reject, account changes, and automation toggles.
4. Keep product claims aligned with `references/socialbu-capabilities.md`; do not guess current plans or platform limits.
5. Do not add secrets, client libraries, or product integrations to this repository.
